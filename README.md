# gltfactor

**Bayesian factor models with a Generalized Lower Triangular (GLT) process prior**

## Overview

`gltfactor` implements Bayesian factor models under a **GLT process prior** currently under develpement.

## Installation

Currently under development. To install from GitHub:

```r
devtools::install_github("tonycanale/glt")
```

## Development status

🚧 Active development

Current features:

- input validation and preprocessing
- Rcpp interface and sampler skeleton
- Updates for: H, pivots, tau probability
